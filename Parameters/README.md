# Parameters

Intermediate datasets. Every file here is regenerated by `Scripts/00-RunAll.R`, except `MaterialFlows/DE_detail_region.csv` and `SP/`, which need local data not in git (see `Scripts/01-PrepareData/README.md`). Script paths are relative to `Scripts/`.

| Folder | Content | Written by |
|---|---|---|
| `UNEP-Materials/` | UNEP IRP material flows (DE, DMC, DMI, IMP, EXP, PTB) by country, region and world | `01-PrepareData/01-Aggregate_UNEP.R` |
| `UN-Population/` | UN WPP 2024 population, historical and forecast | `01-PrepareData/02-Aggregate_UN.R` |
| `Worldbank-GDP/` | World Bank GDP (PPP, constant 2017 intl $; plus MER constant 2015 USD) by country, region and world | `01-PrepareData/03-Aggregate_GDP.R` |
| `MISO-Stock/` | MISO2 stocks and flows by region; ore-grade factor `metal_grade_ore.csv`; 2024 stock totals and age profile | `01-PrepareData/04-Aggregate_MISO.R`, `02-HistoricalStock/03-OreGrade_Factor_g.R`, `02-HistoricalStock/05-UNEP_stock_flow_model.R` |
| `EIA-Capacity/` | EIA installed electricity capacity by region and technology, 1980-2024 | `01-PrepareData/05-Aggregate_EIA_Capacity.R` |
| `MaterialFlows/` | materialflows.net domestic extraction at Level 3 detail by region (`DE_detail_region.csv`); non-ferrous ore DMC split into copper, bauxite, gold and other (`nonfe_split_region.csv`); UNEP DMC without gold (`materials_region_DMC_exGold.csv`) | `01-PrepareData/06-Aggregate_MaterialFlows.R`, `01-PrepareData/07-NonFerrous_Split.R` |
| `SP/` | Ore grade curves and grade indices for iron, copper and bauxite (`*_GradeIndex.csv`), and 2060 grade targets (`GradeTargets_2060.csv`). Deposit-level tables (`*_deposits.csv`) are proprietary S&P data and not in git | `01-PrepareData/08-IronOre_GradeCurve.R`, `01-PrepareData/09-NonFerrous_GradeCurve.R` |
| `Intermediate/` | End-use and sub-end-use flows, historical stock and flow trajectories, scope factor A, secondary flows, and cached figure data (`Figure4_*`, `Figure5_*`, `FigureS2*_*`) | `02-HistoricalStock/*`, `05-Figures/Figure 4 - Climate - PrepareData.R`, `05-Figures/Figure 5 - Sensitivity - PrepareData.R`, `05-Figures/Figure 5 - Alt1 - PrepareData.R` |
| `IIASA-Trajectories/` | SSP drivers (`ssp_drivers.csv`), cleaned ScenarioMIP data, metrics, intensity ratios (`summary_ratio_2060_2025.csv`), climate summary | `03-SSP Trajectories/*` |
| `Simulation/` | Monte Carlo input matrix, sampling bounds, R10 weights (`mc_input_matrix.csv`, `*_ratio_bounds.csv`, `r10_region_weights.csv`, `intensity_world_bounds.csv`); power-sector inputs (`power_*.csv`) | `04-Simulation/01-Sampling.R`, `04-Simulation/02-PowerSector.R` |
