# Parameters

Intermediate datasets. Every file here is regenerated by `Scripts/00-RunAll.R`. Script paths are relative to `Scripts/`.

| Folder | Content | Written by |
|---|---|---|
| `UNEP-Materials/` | UNEP IRP material flows (DE, DMC, DMI, IMP, EXP, PTB) by country, region and world | `01-PrepareData/01-Aggregate_UNEP.R` |
| `UN-Population/` | UN WPP 2024 population, historical and forecast | `01-PrepareData/02-Aggregate_UN.R` |
| `Worldbank-GDP/` | World Bank GDP (constant USD) by country, region and world | `01-PrepareData/03-Aggregate_GDP.R` |
| `MISO-Stock/` | MISO2 stocks and flows by region; ore-grade factor `metal_grade_ore.csv`; 2024 stock totals and age profile | `01-PrepareData/05_Aggregate_MISO.R`, `02-HistoricalStock/02_OreGrade_Factor_g.R`, `02-HistoricalStock/03_UNEP_stock_flow_model.R` |
| `Intermediate/` | End-use and sub-end-use flows, historical stock and flow trajectories, secondary flows, and cached figure data (`Figure4_*`, `Figure5_*`) | `02-HistoricalStock/*`, `05-Figures/Figure 4 - Climate - PrepareData.R`, `05-Figures/Figure 5 - Sensitivity - PrepareData.R` |
| `IIASA-Trajectories/` | SSP drivers (`ssp_drivers.csv`), cleaned ScenarioMIP data, metrics, intensity ratios (`summary_ratio_2060_2025.csv`), climate summary | `03-SSP Trajectories/*` |
| `Simulation/` | Monte Carlo input matrix and sampling bounds | `04-Simulation/01-Sampling.R` |

Some files in `MISO-Stock/` (`phi_nonFe_sweep.csv`, `ore_grade_regression_*`, `phi_trajectories_model_c.csv`) come from exploratory `98*` scripts and are not used by the model.
